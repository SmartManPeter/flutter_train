# 記帳助手

本 App 旨在協助使用者輕鬆記錄日常支出，透過數據統計掌握財務狀況。  
可以藉由掃描電子發票 QR Code 自動擷取消費資訊，減少手動輸入的麻煩，提升記帳效率。

---

## 功能說明

### 📌 支出管理
- 快速記錄每筆開銷，包括 **金額、消費類別與額外備註**。  
- 可自由 **新增、刪除或編輯** 不同的支出類別。  
- 內建 **掃描功能**，可讀取電子發票 QR Code，**自動填入** 消費金額、日期與商店名稱。  

### 📊 交易查詢與篩選
- 根據 **特定時間區間(月份)** 篩選消費記錄。  
- 依據 **類別** 快速檢視特定類型的支出。  

### 📈 數據分析與報告
- 計算 **當月消費最高的支出類別**，幫助使用者掌握財務動向。  
- 每日支出總額清晰呈現，避免超支。  
- **圖表化分類消費比例**，讓使用者更直覺了解資金流向。  

### 🎨 介面與使用體驗
- 友善易懂的操作設計，減少學習成本。  
- **透過掃描功能減少手動輸入**，提高使用便利性。  

### 💾 資料存儲與管理
- **所有記帳資料皆存於本機**，不需網路即可使用，保障個人隱私。  
- 可**綁定 Google 帳號** 可將備份上傳至 **雲端硬碟**，確保資料穩定性。
